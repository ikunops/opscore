## 1. 缺陷 D6：`ui.html` 把目标主机控制的文本未转义地插进 `innerHTML`

`ui.html`（Phase 4 预览控制台）**没有定义任何转义函数**，六处 `innerHTML` 汇全部未转义：

| 汇 | 数据链 |
|---|---|
| `renderServices` | `runOp('system.service.list', {})` 在**目标主机**上执行 `systemctl list-units` ⇒ `steps[0].output` ⇒ 正则解析（`ui.html:239`，`desc` 为整行自由文本）⇒ `${s.unit}/${s.load}/${s.sub}/${s.desc}` 进 `innerHTML`；`${s.unit}` 还进 `data-name="…"` **属性位** |
| 服务表错误行 ×2 | `r.body.error`（服务端错误串，可内嵌**远端命令输出**）进 `innerHTML` |
| `refreshAudit` | 审计事件 `${e.actor}/${e.operation}/${e.target}/${e.detail}/…`——`detail` 是存储的错误串（含远端输出），`target/actor` 是用户/主机输入的字符串 |

**对照组**：`dashboard.html`（Phase 22.2 保护控制台）有 `esc()` 且处处使用——**纪律只落在
后写的那一半**。

### 威胁模型（与本项目的立场一致）

被管主机**在**威胁模型内（整个证据链的存在理由就是「不完全信任被管面」）。恶意/被控目标
主机只需在某个 unit 文件里写 `Description=<img src=x onerror=…>`，管理员打开服务标签页
即触发——同源执行，可读 `localStorage` 的 access token、以管理员身份调用 `/api/*`
⇒ **被管主机 → 管理员浏览器的存储型权限提升**。

## 2. 缺陷 D6b：`dashboard.html` 内联处理器的 `esc()` 不足以封 JS 串上下文

三处 `onclick="f('${esc(x)}')"`（`clearQuota`/`release`/`investFillKill`）：`esc()` 把 `'`
转成 `&#39;`，但**浏览器在编译 JS 之前先解码 HTML 实体**——`&#39;` 还原为字面引号，
字符串被打断。值面（capability 名/principal）当前多为服务端标识符，但 principal 是
用户/管理面输入串 ⇒ 纵深防御必须正确。

## 3. 修法

1. **`ui.html`**：新增 `esc()`（与 dashboard 同实现），六处汇全部封口（含属性位）。
2. **`dashboard.html`**：新增 `jsq()`——**先反斜杠、再 JS 引号/换行、再 HTML 属性层**
   （`\\`→`\\\\`、`'`→`\'`、`\r`/`\n` 转义、`&<>"` 转实体；`'` 保持 `\'` 不做实体，
   因为实体解码会把 `&#39;` 还原回引号），三处内联处理器改用 `jsq()`。
3. **T406 绊线**（`js_esc_guard_test.go`，**声明范围：线级绊线、不是 JS 解析器**）：
   - 两文件必须定义 `esc(`（dashboard 必定义 `jsq(`）且使用量有底线（防提取失效空转）；
   - 含 `${` 的行必须走 `esc(`/`jsq(`，或**每一个**插值表达式匹配显式枚举的安全形状
     （内部类名/数字与长度/已预转义的局部量/安全布尔的条件式/日期格式化/复合开启行）；
   - 嵌套插值**递归**校验（`${cond ? \`…${x}…\` : ""}` 里的 `x` 也要安全）；
   - 含 `onclick="` 且含 `${` 的行**必须**用 `jsq(` 且不得出现 `esc(`。

## 5. 声明的行为变更（穷举）

1. 渲染输出仅对**含 HTML/引号元字符的输入**不同（转义为文本显示）；正常输入视觉零变化。
2. 零 API/协议/服务端行为变化；`.go` 文件零改动（改动面：两个嵌入 HTML + 一个新增测试）。
3. 冻结面零触碰。

## 6. 非目标

- 不引入 DOMPurify 或任何 JS 依赖（零新依赖铁律；`esc`+`jsq`+绊线即既有纪律的补齐）；
- 不把内联 `onclick` 整体重构为 `dataset`+监听器（改面大；`jsq` 把既有模式**正确化**）；
- 不做 CSP（属独立加固项，登记为可选后续）。
